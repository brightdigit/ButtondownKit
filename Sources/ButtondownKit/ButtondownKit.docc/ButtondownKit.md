# ``ButtondownKit``

A small async Swift client for the Buttondown API.

## Overview

ButtondownKit is generated from Buttondown's official OpenAPI spec with
[swift-openapi-generator](https://github.com/apple/swift-openapi-generator) and wrapped in
an ergonomic ``ButtondownClient``. It is used by brightdigit.com to publish newsletter
issues.
